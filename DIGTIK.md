| Threat | Can We Bypass? | Score | Detail |
|---|---|---|---|

| Cloudflare JS Challenge | ❌ No | 0/10 | Requires JS execution + cookie setting. We have no JS engine. |
| AJAX/Fetch-based file delivery | ❌ No | 0/10 | Files served via XHR/fetch after client-side logic runs. Cannot replicate. |
| Obfuscated JS link assembly | ❌ No | 0/10 | Links built from fragments in JS code at runtime. |

## Critical Gaps (Priority Order)

1. **No JavaScript execution** — The single biggest limitation. Entire categories of modern websites are unreachable. A headless browser (Selenium, Playwright, or HtmlUnit) would address this.

2. **No cookie/session management** — Cannot access any login-gated content. Need a CookieManager or HttpClient cookie jar with credential flow support.

3. **No CAPTCHA handling** — Completely blocked by any CAPTCHA. Would need integration with a solving service or avoidance strategy.

4. **No robots.txt compliance** — Currently ignores robots.txt, which means we either get blocked or we crawl disallowed paths unethically. Should parse and respect it.

5. **No HTTP error handling (401/403/429)** — Treats all non-200/non-3xx as generic failure. Should differentiate and adapt (retry with backoff for 429, skip for 403, prompt for 401).

6. **No Referer header** — Many image hosts and file hosts reject requests without a valid Referer matching the originating page.

7. **No Content-Disposition parsing** — Files may save with wrong names if the URL path doesn't contain the real filename.

8. **No download resume** — Large files that fail mid-transfer must restart from zero.

## Recommendations for Improvement

### Tier 1 — Quick Wins (Low Effort, High Impact)
- Add Referer header matching the search result page URL
- Parse Content-Disposition for proper filenames
- Handle 401/403/429 status codes explicitly
- Check and respect robots.txt
- Add cookie jar to HttpClient builder

### Tier 2 — Medium Effort
- Integrate a headless browser (HtmlUnit for Java) for JS-rendered pages
- Implement download resume with Range headers
- Add retry logic with exponential backoff for 429/5xx
- Support custom headers/auth tokens from config

### Tier 3 — High Effort
- Full browser automation (Selenium/Playwright) for Cloudflare and complex JS
- Proxy/VPN rotation for geo-blocked content
- TLS fingerprint randomization
- CAPTCHA service integration

## How to Use This Document

Run the SearchEngineClient and compare download success/failure against this matrix:

```
✅ SUCCESS   → Direct link, no protection
⚠️ PARTIAL  → Got something but may be incomplete/wrong
❌ BLOCKED   → Protection mechanism prevented download
```

Track which category caused the failure to prioritize development effort.
